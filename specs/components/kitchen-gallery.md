# Kitchen Gallery

## 1. Metadata

- Name: Kitchen Gallery
- Category: Content display
- Status: Stable

## 2. Overview

Use for the personal kitchen project list: a static, recipe-book style grid where every dish is its own cover card.

Do not use for a generic image carousel. There is no rolodex navigation, jump targets, or click-to-open lightbox — every dish is shown at once, as if it has no recipe detail to open yet.

## 3. Anatomy

- Intro (title + description)
- Responsive card grid (`auto-fill` columns, one card per dish)
- Card: meta row (`NO. 01` + effort rating), photo, name (zh + en), note

## 4. Tokens used

- `--color-text`, `--color-background`, `--color-background-soft`, `--color-text-muted`, `--color-border-muted`
- `--space-*` (`--space-3xs` through `--space-3xl`)
- `--font-size-label`, `--font-size-caption`
- `--font-weight-regular`, `--font-weight-bold`
- `--font-family-mono`
- `--line-height-body`
- `--radius-lg`
- `--z-base`, `--z-content`

No box-shadow or transition tokens are used — cards are flat, bordered, and static (`box-shadow: none` on the photo).

## 5. Props/API

CSS block `.section--kitchen`; composes the Rating primitive (`.ui-rating`, via `renderKitchenStars`) for the effort indicator. Markup is generated by `renderKitchenCard` / `renderKitchenSection` in `utility/renderHomePage.js` from the `kitchen` block in `content/homeContent.js`.

## 6. States

- Default: all cards render at once in the grid, no interaction to open/expand a card.
- Responsive: grid column `minmax()` and `gap` step down at `$bp-heading` (62.5rem) and again at `$bp-kitchen-grid` (34rem); `.kitchen__bg` also shrinks at `$bp-heading`.
- Note wrapping: names/notes wrap naturally and grow the card height (no truncation); row height is equalized by CSS Grid's default `align-items: stretch`.
- Error: missing images should retain card text (photo container has a `--color-background-soft` fill behind the `<img>`).

## 7. Code example

```html
<article class="kitchen__card">
  <div class="kitchen__cardMeta">
    <span>NO. 01</span>
    <span class="ui-rating kitchen__effort" aria-label="Effort level 2 out of 3">
      <!-- renderKitchenStars -->
    </span>
  </div>
  <div class="kitchen__cardPhoto">
    <img class="kitchen__photo" src="…" alt="…" loading="lazy" />
  </div>
  <div class="kitchen__cardText">
    <div class="kitchen__cardNames">
      <p class="kitchen__nameZh">料理</p>
      <p class="kitchen__nameEn">Dish Name</p>
    </div>
    <div class="kitchen__cardNote">
      <p class="kitchen__note">Note text.</p>
    </div>
  </div>
</article>
```
