# Radius

| Intent | Token |
| --- | --- |
| Square | `--radius-none` |
| Fine detail | `--radius-xs`, `--radius-sm` |
| Control | `--radius-md`, `--radius-lg` |
| Card or media | `--radius-xl` |
| Circle | `--radius-round` |
| Capsule | `--radius-pill` |

Keep radius consistent across connected surfaces. Do not mix more than two radius levels inside one component.
