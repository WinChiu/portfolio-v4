# Color

Use semantic Layer 2 tokens. Never select a primitive by appearance alone.

| Role | Token |
| --- | --- |
| Primary text | `--color-text` |
| Muted text | `--color-text-muted`, `--color-text-subtle` |
| Page surface | `--color-background`, `--color-background-soft` |
| Link | `--color-link`, `--color-link-hover` |
| Border | `--color-border`, `--color-border-muted` |
| Primary action | `--color-interactive`, `--color-interactive-hover` |
| Disabled action | `--color-interactive-disabled` |
| Focus | `--color-focus`, `--color-focus-soft` |
| Overlay | `--color-overlay`, `--color-zoom-overlay` |

Text and icons must retain sufficient contrast against their surface. Interactive changes must not rely on color alone.
