# Components

A component is one folder that owns everything about one piece of UI: its markup, its styles and, if it has any, its behavior.

```
components/
├─ escape.js                 shared helper (UI.escape)
├─ Button/
│  ├─ button.js              render function: UI.Button({ ... }) -> HTML string
│  └─ _button.scss           styles, wired in from style/style.scss and style/workStyle.scss
├─ MenuItem/  EffortMeter/  Leader/  PhotoCard/  ProjectCard/
└─ HairlineCover/            a custom element (<hairline-cover>), loaded through components.js
```

## How a component is written

- **Markup** is a pure function: props in, HTML string out. It has no side effects and does not touch the DOM, so the same file runs in the browser (`window.UI.Button`) and in the Node build scripts (`require('../components/Button/button.js')`). Each file is a small UMD wrapper; there is no bundler.
- **Text is escaped** inside the component (`UI.escape`), so call sites pass plain text. A prop that is documented as HTML (for example a button `label`) is inserted as given.
- **Styles** live next to the markup in `_<name>.scss` and are `@use`d from the page's entry file. They consume `--sys-*` and `--comp-*` tokens only (see `style/README.md`); the token audit fails the build otherwise. A component takes its accent color from the surrounding chapter or project through `--accent-ink` instead of hard-coding one.
- **Class names** follow `block`, `block__element`, `block--modifier` (`button`, `button__label`, `button--outline`). Pages style their own layout around a component with their own classes, never by reaching into its internals.
- **Behavior hooks** are the component's own class names (`.menu-item`, `.button`). Scripts such as `landingPageAnimation.js` and `kitchenMenu.js` select those, so renaming a class means updating the script in the same change.
- **Docs**: each component has a spec in `specs/components/` (generated by `npm run specs:generate` from `scripts/generate-component-specs.js`).

## Using one

```html
<script src="components/escape.js"></script>
<script src="components/Button/button.js"></script>
<script>
  el.innerHTML = UI.Button({ label: 'View project', href: 'pages/en/rfid.html', variant: 'outline', icon: '→' });
</script>
```

```js
// Node (templates/)
const Button = require('../components/Button/button.js');
```

A component that is made of others lists them as arguments of its wrapper (`MenuItem` uses `Leader` and `EffortMeter`), so load the dependencies first.
